# 物品注释用的表

| 文件 | 内容 | 进不进公开仓库 |
|---|---|---|
| `comments.tsv` | 暗金 / 套装 / 符文之语的一句点评（按一个第三方模组的点评逐条改写的） | **不进**。属于改编，公开仓库不带；没有这份表时不加点评，其余注释照常 |
| `oldnames.tsv` | 旧译名对照表：把一部分名字换回老玩家熟悉的旧版中文译名 | **不进**。它是成套的他人译名，公开仓库不带；没有这份表时「换回旧译名」这一步自动不做，其余注释照常 |

## 自备旧译名对照表

放一份 `oldnames.tsv` 到本目录即启用。制表符分隔、UTF-8、首行是表头：

```
文件	键	原文校验	旧译名
item-names	KhalimFlail	2717cc0f	（你要换成的名字）
```

- `文件`：游戏字符串文件名，不带 `.json`（在游戏资源的 `data/local/lng/strings/` 下）
- `键`：该文件里那一条的 `Key`
- `原文校验`：这一条现行简体中文原文（UTF-8）的 SHA-1 前 8 位十六进制——构建时逐条核对，原文变了（游戏换了版本）会报错，免得换错
- `旧译名`：换成的名字；要换行写 `\n`

## 自备点评表

放一份 `comments.tsv` 到本目录即启用。制表符分隔、UTF-8、首行是表头；看 `annot_strings.py` 的 `comments()` 用到的列：

```
文件	键	名字颜色	点评
item-names	（字符串的 Key）	unique	（你写的一句话）
```

- `文件`：`item-names`（暗金、套装件）或 `item-runes`（符文之语）
- `键`：该条字符串的 `Key`；表里的键在游戏字符串表里找不到会报错
- `名字颜色`：`set` = 套装（绿），其余按暗金（金）
- `点评`：显示在名字下面的一行。里面提到的技能名要用换回旧译名之后的名字（如果你同时带了旧译名对照表）
