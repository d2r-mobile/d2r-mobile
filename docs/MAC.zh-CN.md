# 在 Mac 上玩（macOS App，第一版）

English: [MAC.md](MAC.md)

Apple 芯片的 Mac 可以把本项目构建成一个原生的 macOS App：`D2R Mobile.app`，双击启动，键盘、鼠标、手柄都能用。它跑的是同一份游戏、同一套我们加的功能（秘境、珍宝匣、编年史、自定义页等），界面用的是原版的手柄版界面。

**先说在前面：这一版还没有人真的坐下来玩过。**键盘按键、实体手柄、选资源文件夹的对话框、⌘Q 与菜单点击、真人手感——这五项都没有人实际操作过。下面写「验过」的，都是无人值守跑出来的：按键用测试脚本注入，鼠标用测试入口注入，退出、全屏、改窗口大小用测试开关。欢迎第一批试用的人把结果开 Issue 告诉我们。

## 构建

前提与 iOS 那条路相同：游戏文件放到位，`./setup.sh` 跑完（见首页「开始使用」）。然后：

```bash
source ~/dm-work/build/cache/dm/venv/bin/activate
dm/tools/mac_app.sh
```

约十几秒，产出 `~/dm-work/out/macapp/D2R Mobile.app`（约 3 MB）。想放到别处：`dm/tools/mac_app.sh <输出目录>`。

这个 App 里只有我们自己的程序。改写后的游戏程序、着色器库、界面覆盖层都是从你的游戏文件做出来的，它们留在你的工作区（`~/dm-work`）里，App 只记着它们的位置——所以**这个 App 只能在构建它的这台 Mac 上跑**，请不要拷给别人，也不要删掉工作区。签名用的是本机临时签名，不需要开发者账号，也不需要登记设备。

## 第一次打开

双击 `D2R Mobile.app`。第一次启动会请你选**游戏资源文件夹**：选 `~/dm-work/data/switch/3.3.94012/Update`（或它里面的 `RomFS`）即可，里面要有 `data` 文件夹。选错了会说明原因并让你重选；选对之后会记住，下次不再问。

接着会弹一次键位对照表，之后在菜单栏「帮助」里随时能看。

## 东西放在哪

- 存档：`~/Library/Application Support/D2R Mobile/save`
- 日志：`~/Library/Logs/D2R Mobile/host.log`（上一次运行的是 `host.prev.log`）。报问题时请附上它。

## 键盘 ↔ 手柄

界面上的按键提示显示的是手柄字母，对应的键盘按键如下：

| 手柄 | 键盘 |
|---|---|
| 左摇杆（移动） | W A S D |
| 十字键 | 方向键 |
| A 确认 / B 返回 / X / Y | J / K / U / I |
| L / R | Q / E |
| ZL / ZR | Z / C |
| 按左摇杆 / 按右摇杆 | F / G |
| ＋（菜单）/ −（地图） | 回车 / Tab |

鼠标：左键点目标或界面，右键 = B（返回 / 关面板），滚轮滚列表。接上手柄直接可用，与键盘并存。

菜单栏有「显示 → 全屏（⌃⌘F）」和「退出（⌘Q）」。窗口可以随意拉大小，游戏画面保持 16:9 居中。

## 退出与存盘

关窗口、⌘Q、菜单里点退出，在任何状态下都会先存盘再退：局内、暂停菜单开着、面板开着、读取画面、秘境面板开着各验过一局。最多等 3 秒；到点还没存成，会在日志里记一行「未存盘退出」。

## 这一版的操作方式

- **移动**用 W A S D 或手柄摇杆。鼠标点到怪物、NPC、物件会走过去交互；点空地不会走。
- **物品**的整理、穿脱、买卖用键盘或手柄的光标操作：W A S D 把光标移到物品上，按底栏提示的键。例如在商人处买东西：光标移到货物上（底栏出现「A 购买」）→ 按 J → 确认框里再按 J。
- **界面**是原版的手柄版界面，我们加的页面（自定义页、珍宝匣、编年史、秘境选层等）都在里面。

## 这一版还没有的

- 鼠标点地面走路、鼠标对物品的长按 / 双击 / 拖放。
- 手柄上 ZR 空格的免费回城。
- 秘境左侧的任务栏。
- iCloud 存档同步、更新检查、分享诊断日志。
