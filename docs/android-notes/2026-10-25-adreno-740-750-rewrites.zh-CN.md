# Adreno 740 / 750 着色器兼容

English: [2026-10-25-adreno-740-750-rewrites.md](2026-10-25-adreno-740-750-rewrites.md)

高通 Adreno 740–799 机型默认关闭四元组导数和 warp32 着色器改写。部分系统驱动能接收改写后的 SPIR-V，却会在执行时出错或停滞。机型策略优先于 Android 启动器设置的环境变量默认值。

## 设置

策略检查高通厂商 ID `0x5143`，以及 `properties.deviceName` 中的三位 Adreno 型号。Adreno 730、Adreno 830 和其他厂商保持原有默认值。

显式设置 `files/dm/gfx-quad-derivatives` 或 `files/dm/gfx-warp32` 标记文件仍然优先：`0` 关闭对应改写，`1` 开启。这两个开关不需要重新生成导入包。

## 日志

启动日志会说明命中的机型策略及两个开关的最终取值。栅栏超时表示 GPU 在等待时限内尚未完成提交。命令池复位日志记录等待时限；超时恢复仍会先确认 GPU 完成，再复用命令。

CPU 策略检查位于 `dm/gfx/vulkan/engine/tests/adreno_policy_test.cpp`，覆盖机型识别和标记文件、环境变量的优先顺序。它不代表手机上的实际画面或性能。
