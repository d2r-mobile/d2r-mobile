# Adreno 740 / 750 shader compatibility

中文：[2026-10-25-adreno-740-750-rewrites.zh-CN.md](2026-10-25-adreno-740-750-rewrites.zh-CN.md)

The quad-derivative and warp32 shader rewrites default off for Qualcomm Adreno models 740–799. Some system drivers accept the rewritten SPIR-V but fault or stall when executing it. The device policy takes precedence over the environment defaults set by the Android launcher.

## Settings

The policy checks Qualcomm vendor ID `0x5143` and the three-digit Adreno model in `properties.deviceName`. Adreno 730, Adreno 830 and other vendors keep their existing defaults.

An explicit `files/dm/gfx-quad-derivatives` or `files/dm/gfx-warp32` marker still takes precedence: `0` disables that rewrite; `1` enables it. These switches do not require regenerating the import pack.

## Diagnostics

Startup logs identify the device policy and the resulting values of both switches. A fence timeout means the GPU has not completed the submission within the wait interval. The command-pool reset log reports the interval; timeout recovery still waits for GPU completion before reusing commands.

The CPU policy check is `dm/gfx/vulkan/engine/tests/adreno_policy_test.cpp`. It covers device matching and marker/environment precedence. It does not establish rendered output or performance on a phone.
